# Isaac Lab：任意の位置のCubeをつかんで持ち上げる

**XY各±30mm内の35地点で、pick・3秒維持に成功**

[English](README_ENG.md)

## 目的と結果
基準配置からXY各±30mm内でCube位置を変更し、同じ画像位置推定モデルと段階制御によるpick・成功後3秒維持を評価しました。固定点とランダム点を合わせた35種類の位置で全試行が合格しました。各地点1試行の集計であり、領域全体や一般的な成功率100%を保証する結果ではありません。

## 構成
テーブル・手首カメラ画像とロボット状態からCubeとの相対位置を推定し、環境座標の推定位置をEMA（係数0.2）で平滑化します。接近・下降・把持・持上げ・維持は明示的な段階制御で実行します。評価時の正解Cube位置は採点用で、制御入力には使いません。

これは学習済み画像推定＋段階制御です。今回、言語指示切替やend-to-end行動学習の成功を検証したものではありません。

## 評価
- 既存26地点の一巡：26/26
- ±30mm内の新規ランダム5地点：5/5
- X正側の領域別追加4地点：4/4
- 全35地点の最低保持高さ：127.87mm
- 全35地点の最大水平変位：10.45mm
- 主な判定：初期静定高さ＋100mm以上の持上げ、成功後3秒間の高さ維持、水平変位50mm以内。接触力による把持の検証は含みません。

## 改善の過程
画像位置推定が下降中にCubeを実際より低く見積もり、閉鎖条件に到達しない問題を確認しました。失敗時の画像と同時刻の正解位置を収集して学習を更新し、±20mmの評価を通過しました。±30mmの残る失敗地点では、失敗軌道の追加だけでは接近段階が悪化しました。正解位置による制御診断で成功を確認し、正常な接近から維持までの全軌道データを追加した候補で35地点の評価を通過しました。

## デモ動画
