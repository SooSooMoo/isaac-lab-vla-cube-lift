# 推論と段階制御

[English](README_ENG.md)

## 処理順序
1. 動作前の2画像・状態を取り出す。
2. 相対位置を推定し、EEF位置を足してCubeの環境座標へ変換。
3. 前回値80%・現在値20%のEMAで平滑化。試行ごとに初期化。
4. 接近は推定位置の上100mm、下降・閉鎖は推定位置を目標とする。
5. 位置10mm以内・姿勢0.1rad以内が5ステップ連続で成立すると接近から下降、下降から閉鎖へ進む。閉鎖20ステップ後に持上げへ進む。
6. 閉鎖移行時の推定位置を基準に180mm上方を持上げ目標とし、維持時も目標を固定する。

真値Cube位置は採点・記録用です。画像評価の制御入力ではありません。実装は[評価本体](../snapshots/check_visual_validation26.py)のSOURCE内。実行は相対姿勢IK、DLS、環境内の手先フレームとIKオフセットを一致させます。

## 境界条件
推定誤差が変わると画像と軌道も変わり、オフライン誤差が小さくても失敗し得ます。EMAだけで12/13を解消したとは主張しません。最終モデルは追加データによる学習更新を含みます。
