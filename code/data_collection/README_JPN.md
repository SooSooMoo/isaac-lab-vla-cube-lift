# データ収集

[English](README_ENG.md)

## 2種類の収集
- 正解位置を用いる教師（oracle）制御：正常な接近から持上げ・3秒維持までの画像と位置を記録。教師成功を画像推定による成功として数えません。
- 画像推定で失敗した試行：その試行の画像・状態と同時刻の正解Cube位置を記録。真値はラベルのみで制御には使いません。

最終学習には（−20,+20mm）の失敗観測と（+30,−30mm）の正常な教師全軌道を使用。（+30,−30mm）の失敗観測のみを追加した不採用候補のデータは最終学習に含めません。

## 時刻と形式
観測とCubeラベルは同じ`env.step`前に取得。目標は`cube_pre − eef_pre`です。通常データは`data/demo_0/obs`、教師全軌道ラベルは`data/demo_0/labels/cube_minus_eef_env_m`、失敗記録は`obs`と`true_cube_pre`です。以前のエピソードは別NPZのラベルを参照します。

[23エピソードの一覧](../../datasets/README_JPN.md)と[依存一覧](../../datasets/dependency_manifest.json)を参照してください。今回の公開スナップショットには収集専用スクリプトとHDF5本体を含めていません。このフォルダは収集方法の説明です。
