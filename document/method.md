# 方法とモデル構成

1. 卓上・手首の200×200 RGB画像をImageNet平均・標準偏差で正規化。
2. 手先位置、xyzw姿勢、指位置、step/1200の進行度と、言語埋め込みを結合。
3. 基礎方策の融合特徴に学習済み残差を適用。腕の6出力と開閉出力を生成。
4. 学習済み線形開閉補正をロジットに加算。
5. 融合特徴を標準化し、学習済みスコアを0～1へ制限。XY指令に `1 - score` を乗算。

最終構成は4ファイルに分かれていますが、両指示で同じ構成を実行します。固定ステップで別の方策へ切り替える処理はありません。特徴には進行度があるため、学習済み減衰が時刻情報を利用しないとは主張しません。

教師介入による診断軌道を学習目標として利用しました。介入時の成功と、最終学習済み方策による評価結果は区別します。固定入力上での出力保持は、閉ループで同じ軌道を保証しません。最終評価ではシミュレータで両タスクと再実行を確認しました。

現行ローダーは `code/inference/shared_loader.py`。検証時の実装を評価スクリプトからそのまま抽出しています。元Podの依存パスを使う実験コードで、単体配布用SDKではありません。
