## 1. 目的と検証範囲

同じ言語条件付きモデル構成で、`move above the cube` と `pick up the cube` を実行するIsaac Labプロジェクトです。評価は固定初期状態とこの2指示を対象としています。

この文書は、方法、環境、開発経緯、再現手順、結果と公開状況をまとめたものです。コードは `../code/`、学習関連データは `../datasets/`、モデルと評価記録は `../result/` にあります。

## 2. 方法とモデル構成

1. 卓上・手首カメラの200×200 RGB画像をImageNetの平均・標準偏差で正規化します。
2. 手先位置、xyzw形式の姿勢、指位置、`step/1200` の進行度、言語埋め込みを入力します。
3. 基礎方策の融合特徴に学習済み残差を適用し、腕の6成分と開閉出力を生成します。
4. 学習済み線形補正を開閉ロジットに加えます。
5. 標準化した融合特徴から学習済みスコアを計算し、0～1に制限してXY指令に `1 - score` を掛けます。

最終構成は基礎モデル、視覚アダプター、開閉補正、XY減衰の4ファイルです。両指示で同じ構成を使用し、実行中に固定ステップで別の方策へ切り替える処理はありません。ただし入力特徴には進行度が含まれます。

教師介入の診断軌道を追加学習の目標として利用しました。教師介入時の結果と、自律実行による評価結果を区別しています。固定入力で出力を保持できても、観測が変化する実行中の軌道保持は保証されません。

実装は [shared_loader.py](../code/inference/shared_loader.py)、モデルの識別情報は [manifest.json](../result/model/manifest.json) を参照してください。

## 4. 実行環境

記録された環境はPython 3.12、PyTorch 2.11.0+cu128、NVIDIA GeForce RTX 4090です。Pythonは `/isaac-sim/python.sh`、Isaac Labは `/workspace/IsaacLab-develop/isaaclab.sh` を使用しています。動画エンコーダーはimageio-ffmpeg同梱のffmpegです。

必要なカスタムタスクは `IsaacContrib-Lift-Cube-Franka-IK-Rel-Visuomotor` です。評価コードは姿勢関数のxyzw形式を確認します。wxyz形式やカスタムタスクのない環境は、そのまま互換とは扱えません。

記録上のNGXライブラリは `/workspace/step3/ngx_runtime_580.65.06_cgbe5u2a/lib` にあり、評価プロセスの `LD_LIBRARY_PATH` に追加されます。NGX修復後に初期カメラ入力の一致を確認しています。NVIDIAバイナリは再配布条件の確認が必要で、通常のソース配布には含めません。

検証用ランタイムは初期状態のcuDNN benchmark=Trueを確認してFalseへ変更します。他の想定値はdeterministic algorithms=False、cuDNN deterministic=False、matmul TF32=False、cuDNN TF32=True、`CUBLAS_WORKSPACE_CONFIG` 未設定です。これらは当時の実験条件であり、一般的な推奨設定ではありません。

正確な環境情報は保存済み環境記録で確認してください。既存のIsaac Sim/Kit、カスタムIsaac Lab、Pythonパッケージ、外部USDアセットに依存しており、クリーン環境での再構築は未検証です。

## 6. 再現と確認の順序

現在のPod上のリポジトリは `/workspace/step3/isaac-lab-vla-cube-lift` です。以下は依存環境と元の実験ファイルが揃ったPodで実行するコマンドです。

```bash
cd /workspace/step3/isaac-lab-vla-cube-lift
/isaac-sim/python.sh code/tools/check_package.py
/isaac-sim/python.sh code/tools/check_package.py --require-imported
```

パッケージ確認後、評価が必要な場合に実行します。

```bash
bash code/evaluation/verify_xy_attenuation_above.sh
bash code/evaluation/verify_xy_attenuation1300.sh
bash code/evaluation/repeat_both_xy_attenuation.sh
```

評価スクリプトは元Podの絶対パスやラッパーにも依存します。リポジトリの取得だけでは実行準備完了にはなりません。ソース整合性、取り込み済みアーティファクト、シミュレータの評価は別の確認です。

過去の `update_portfolio_on_pod.py` は旧名 `isaac-lab-vla-cube-lift_2` と当時の配布ZIPを対象にした更新ツールです。現在のフォルダへ再実行する前に、その対象と変更内容を確認してください。
