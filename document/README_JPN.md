# 構成と判定条件

200×200 RGB画像2枚を共通のResNet18で処理します。9次元のロボット状態と、埋め込み＋GRUによる言語特徴を統合し、256次元の特徴を128次元GRUへ入力します。出力は腕6次元とグリッパー1次元です。隠れ状態はエピソードごとにリセットし、時間順に更新します。

指示は `pick up the cube` のみです。ポリシーには段階ラベルやステップ番号を入力しません。

判定は静定後のCube高さ＋100mm以上への持上げと成功後3秒の保持です。持上げ・保持の水平変位上限は50mmで、関節範囲と有限値も検査します。制御周期は0.02秒、取得期限は1300ステップです。

最終調整では成功軌道の開閉判断を維持する制約と、診断で得た閉鎖ラベルからグリッパー出力重みを求めました。診断の動作上書きによる成功と、学習済みモデルの自律成功は区別しています。
