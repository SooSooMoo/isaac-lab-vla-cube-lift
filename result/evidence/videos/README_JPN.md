ファイル名は `above_trimmed.mp4` などです。50 fpsの実時間映像で、左が卓上カメラ、右が手首カメラです。各フレームは行動前の観測です。

trimmed版は延長版の先頭からの連続映像です。aboveは成功後約1.4秒、pickは約1.0秒を残して末尾を除去しています。フリーズ加工や別動作の挿入はありません。全延長版にはaboveの位置ずれとpickの落下が含まれます。末尾編集は制御上の長時間保持の改善ではありません。

動画はPodの取り込み処理で配置されます。`.gitignore` は動画を通常の追加対象から除外するため、PodとGitHubで存在する動画が異なる場合があります。公開する動画は別途アップロードし、掲載先へのリンクを設定してください。
