# 制限事項とVLAへのロードマップ

## 現在の到達点

- ランダム初期位置から50件の成功デモを収集
- 卓上・手首カメラとロボット状態をHDF5へ保存
- Robomimic BC-RNN-GMMを200 epoch学習
- 閉ループ推論で1件のキューブ把持・持ち上げに成功
- 成功行動列の保存と完全リプレイに成功

## 制限事項

- 初期評価は1/10、記録付きseed探索は1/48成功
- キューブへ斜めに接近し、押してしまう場合がある
- 把持途中でキューブを落とす場合がある
- 同じseedと初期位置だけでは成功を保証できない
- `pick up the cube` はHDF5メタデータであり、モデル入力ではない
- 現在は言語条件付きVLAではなく、視覚運動模倣学習のbaselineである

## 成功率30%以上への改善候補

1. 真上から接近する成功デモを追加する
2. 接近・把持・持ち上げの各段階を均等に学習させる
3. DAggerで失敗状態に教師行動を追加する
4. 行動速度とIK-Relスケールを調整する
5. 学習用と評価用の初期位置を分離する
6. 複数seedのrollout成功率でcheckpointを選択する

## VLAへの発展

複数色のキューブと複数指示を使用します。

```text
pick up the red cube
pick up the blue cube
do not pick up any cube
```

同じ画像でも指示によって正解行動が変わるデータを収集し、次の構成で方策を学習します。

```text
画像特徴 + 言語特徴 + ロボット状態 -> 行動
```

## 評価項目

- 指定色のキューブを持ち上げた割合
- 別の色を誤って選択した割合
- 未学習配置での成功率
- 言い換え指示での成功率
- `do not pick up`で動作しなかった割合

## 最終目標

言語指示を変えると対象や行動が変化することを示し、現在の単一タスク方策を言語条件付きVLAへ発展させます。
