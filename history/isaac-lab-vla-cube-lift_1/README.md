## Overview

This repository presents an Isaac Lab visuomotor imitation-learning baseline toward a future Vision-Language-Action system.

本リポジトリは、将来のVision-Language-Actionシステムへの発展を目的とした、Isaac Lab上の視覚運動模倣学習baselineです。

The current Robomimic BC-RNN-GMM policy uses table and wrist RGB images plus robot state to predict IK-Rel and gripper actions. The fixed instruction `pick up the cube` is stored as dataset metadata but is not used as a language input by the current model.

現在のRobomimic BC-RNN-GMM方策は、卓上・手首RGB画像とロボット状態からIK-Rel・グリッパー行動を予測します。固定指示 `pick up the cube` はデータセットのメタデータに保存されていますが、現在のモデルへの言語入力には使用していません。

## Results

- 50 successful state-machine demonstrations
- 200 training epochs
- Initial closed-loop evaluation: 1/10 successful rollouts
- Recorded seed search: 1/48 successful rollouts
- Exact replay of the saved successful trajectory: 1/1
