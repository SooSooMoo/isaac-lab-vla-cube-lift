# 06 動画

このフォルダには、学習済み方策の評価結果と成功軌道の完全リプレイを示す動画・画像を収録しています。

## ファイル

| ファイル | 内容 |
| --- | --- |
| `policy_success.mp4` | 学習済みBC-RNN-GMM方策が閉ループ推論でキューブの把持・持ち上げに成功した例 |
| `policy_failure.mp4` | 学習済み方策がキューブの把持に失敗した代表例 |
| `exact_replay_success.mp4` | 成功時に保存した101ステップの行動列を同じ初期位置から完全リプレイした動画 |
| `franka_cube_lift_success.png` | README先頭に掲載する成功場面の静止画 |

## 重要な区別

`policy_success.mp4` は、カメラ画像とロボット状態を入力した学習済み方策が、シミュレーションを観測しながら行動を出力した閉ループ成功です。

`exact_replay_success.mp4` は、閉ループ成功時に保存した行動列を再生した結果です。モデルが各stepで新しく行動を推論している動画ではありません。

## 評価結果

- 初期評価: 1/10成功
- 記録付きseed探索: 1/48成功
- 成功seed: 2058
- 完全リプレイ: 1/1成功

現在の閉ループ成功率は低いため、成功動画だけでなく失敗動画も公開し、方策の到達点と制限事項を明確にしています。

## GitHubでの表示

GitHubはMP4をREADME内で常に直接再生できるとは限りません。READMEから各動画へのリンクを設け、成功場面はPNG画像として表示します。
