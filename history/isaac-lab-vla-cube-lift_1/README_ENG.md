# Robot Imitation Learning for VLAs Using Isaac Lab: Franka Cube Lift

![Franka Panda grasping the cube](06_videos/franka_cube_lift_success.png)

*Successful cube grasp by the trained Robomimic BC-RNN policy*

## Project Overview

This project explores the development of a Vision-Language-Action (VLA) robot in NVIDIA Isaac Lab.

The current implementation is a vision-based action-learning baseline for future VLA development. A Franka Panda observes the scene through table and wrist RGB cameras and robot proprioception, then attempts to approach, grasp, and lift a cube.

> **Current status:** Vision and Action are implemented. Language is not yet included in the model input, so this is not a complete VLA system.

## Workflow

1. `01_environment`: Validate the Isaac Lab environment and observations
2. `02_data_collection`: Collect successful state-machine demonstrations
3. `03_training`: Train the Robomimic BC-RNN-GMM policy
4. `04_evaluation`: Evaluate the trained policy in closed loop
5. `05_reproduction`: Replay the exact successful action sequence
6. `06_videos`: Review success, failure, and replay videos

## 01. Environment

- GPU: NVIDIA GeForce RTX 4090
- Isaac Sim: 6.0.1 RC
- Isaac Lab: develop branch
- Robot: Franka Panda
- Task: `IsaacContrib-Lift-Cube-Franka-IK-Rel-Visuomotor`
- Control: Differential IK, relative pose
- Control frequency: 50 Hz
- Imitation-learning framework: Robomimic 0.4.0

### Observations

| Key | Description |
|---|---|
| `table_cam` | Table-mounted RGB camera, 200 × 200 × 3 |
| `wrist_cam` | Wrist-mounted RGB camera, 200 × 200 × 3 |
| `eef_pos` | End-effector position |
| `eef_quat` | End-effector orientation |
| `gripper_pos` | Gripper joint state |

### Actions

```text
[x, y, z, rx, ry, rz, gripper]
```

The first six dimensions are relative IK commands, and the final dimension is the gripper command.

## 02. Data Collection

Using an Isaac Lab state machine as the expert, 50 successful demonstrations were collected from randomized initial cube positions. The Robomimic HDF5 dataset contains sequential camera images, robot states, and expert actions.

Language instructions are not included in the current training data or model input. The complete dataset will be distributed through GitHub Releases or external storage after its size is confirmed.

## 03. Training

- Algorithm: Behavior Cloning
- Policy: BC-RNN-GMM
- Demonstrations: 50 successful episodes
- Epochs: 200
- Checkpoint: `model_epoch_200.pth`
- Configuration: `03_training/bc_rnn_image_lift.json`

Training used the official Isaac Lab script:

```text
/workspace/IsaacLab-develop/scripts/imitation_learning/robomimic/train.py
```

## 04. Evaluation

| Evaluation | Result |
|---|---:|
| Initial 10 rollouts | 1/10 |
| Seed search | 1/48 |
| Successful seed | 2058 |
| Successful initial position | (0.426184, 0.179950, 0.055000) |
| Offline overall MAE | 0.1127 |
| Gripper accuracy | 97.99% |

See [`04_evaluation/evaluation_summary.csv`](04_evaluation/evaluation_summary.csv) for the machine-readable results.

Closed-loop success remains low and the policy has not achieved stable grasping. However, one genuine successful trajectory generated by the trained policy was observed.

## Limitations

- Language is not yet included in the model input.
- The successful result cannot be reproduced using the seed alone.
- The gripper sometimes approaches diagonally, contacts the cube, and pushes it away.
- Errors accumulate during closed-loop inference.
- The current success rate has not reached the portfolio target of 30%.

## Path Toward VLA

The next stage will introduce multiple colored cubes and language instructions, combining visual features, language features, and robot state.

```text
pick up the red cube
pick up the blue cube
do not pick up any cube
```
